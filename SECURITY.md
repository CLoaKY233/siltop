# Security

siltop reads system metrics locally and needs no administrator privileges. Its only
network request is an optional, opt-in daily update check against the GitHub releases API.

If you find a way to make it crash other processes, signal a process it should not, leak
data, or escalate privileges, please report it privately through
[GitHub's private vulnerability reporting](https://github.com/CLoaKY233/siltop/security/advisories/new)
or by email to laysheth1@gmail.com, with the details and a reproduction. Please do not open
a public issue. You will get a reply within 72 hours.
